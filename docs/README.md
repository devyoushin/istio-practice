# Istio Docs

Istio 학습 문서는 주제별로 나눠 관리합니다.

| 폴더 | 내용 |
|------|------|
| `install/` | 설치, 업그레이드, 사이드카 주입, 성능 튜닝 |
| `traffic-management/` | VirtualService, DestinationRule, Canary, Egress, 복원력 |
| `security/` | mTLS, AuthorizationPolicy, 인증서, 외부 CA |
| `observability/` | Prometheus, Grafana, Kiali, Jaeger, tracing |
| `envoy/` | Envoy 아키텍처, xDS, filter chain, admin/debug |
| `agents/` | Claude 전문 에이전트 프롬프트 |
| `rules/` | 문서 작성과 운영 규칙 |
| `templates/` | 재사용 문서 템플릿 |

처음 읽을 문서는 `install/install.md`입니다.
